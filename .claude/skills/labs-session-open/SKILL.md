# Labs Session Open (SOP L3)

1. Open the Current SOP page "L3. Session Open" in Notion with the Notion connector:
   https://app.notion.com/p/40e3cf592e438155913fdad983e02b9a
2. Follow every step exactly as written there. The Notion page is the source of truth; this file only points to it.
3. Stop after the orientation report and wait for Amir's go-ahead before writing any code.

## If the Notion connector is unavailable

Say so at the top of the orientation report, then:

1. Use the ticket Ref from the prompt, or propose a ticket (Type, title, project) for Amir to create.
2. Read CLAUDE.md and the repo's docs.
3. Paste the literal output of `git branch --show-current`, `git log --oneline -3` and `git status`.
4. Write the orientation report using the Methodology template.
5. Ask Amir or Claude chat for the Notion context: Current State, open tickets, Locked decisions, Known Issues.
6. Stop and wait for go-ahead.
